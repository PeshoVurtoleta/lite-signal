HONEST FRAMING (the claim that reproduces):
  lite-signal's differentiated position is ALLOCATION, not raw propagation speed.
  On these shapes lite runs at parity-to-behind alien on throughput (weak on deep/
  layered propagation -- the DEEP CHAIN / burst family), while allocating one to four
  orders of magnitude less transient heap (see bench/benchmark.mjs heap columns, the
  zero-GC microscope). The headline is 'competitive throughput with dramatically lower
  GC pressure', not 'fastest dynamic-graph engine'.

  1. No number is published unless its file carries a machine stamp and the sweep
     exited 0 (dead-sink / counter / checksum / expected / sentinel / stamp guards).
  2. The mirror tracks Andrii verbatim; divergence for identical engine bytes is a
     harness bug (run mirror.mjs --self-verify). Shape edits only by re-porting.
  3. One shape name = one definition, repo-wide. Approximations deleted, not renamed.
  4. lite's config is fixed per file and echoed by the stamp. sab is a production
     feature, not a benchmark knob.
