STANDING RULES (enforced by the harness, not by prose):
  1. Built only from a dir with the COMPLETE marker run-all-mirror.sh writes after every
     FW=<engine> mirror.mjs process exited 0. No sentinel ran. The mirror's in-process
     counter / checksum guards compare engines inside ONE process, so with one engine
     per process they check nothing; lib/rowcheck.mjs compares the rep files across
     engines instead.
     report.mjs itself checked: the marker (protocol, reps, engines vs the files), one
     engine sha / protocol / host per engine, equal rep counts across engines, and every
     row in every rep file. lib/rowcheck.mjs checked: every counter equal across each
     engine's reps; edgesTraversed, sum and checksum equal across engines; no required
     token missing and no zero sum / checksum; every row on >= 2 engines; one host, node,
     harness sha, engine sha, protocol, config and adapter across all stamps; quick=false
     and the COMPLETE marker's captureId in every stamp.
  2. The mirror is a port of Andrii's suite, not a copy; a counter divergence for
     identical engine bytes is a harness bug (run mirror.mjs --self-verify). Shape
     edits only by re-porting.
  3. One shape name = one definition, repo-wide. Approximations deleted, not renamed.
  4. lite's config is fixed per file and echoed by the stamp. sab is a production
     feature, not a benchmark knob.
  5. Cross-protocol / cross-host comparisons cite (stamp, protocol) or are not made.
