--- 1.6.0 GAP REVIEW ---
1.6.0 adds createScope + describe and fixes the disposal crash. scope-torture
already covered createScope adoption + the crash fuzz. The UNCHECKED surface was
the read-only INTROSPECTION API (describe, nodeId, hasObservers, isTracking,
forEachObserver/Source/Owned, ownerOf, observeObservers) -- the substrate
lite-devtools / lite-studio build on. The whole suite exercised none of it.

introspect-torture closes that. Two load-bearing properties:
  1. WALK AGREEMENT -- forEachSource/Observer must match the real edge set and
     track dynamic rewiring (cross-checked vs the reference dep set + op-3/4 lane).
  2. THE ABA GEN-STAMP GUARD -- a descriptor captured before dispose+recycle must
     resolve to nothing, never the new resident. Broken, devtools would read a
     recycled node's edges as the old node's: silent data corruption. This guard
     is invisible to every value/wakeup/work oracle; introspect-torture is the
     ONLY scenario that catches its removal.

Note (self-correction recorded): observeObservers hooks are onConnect (0->1) and
onDisconnect (1->0) transitions, NOT per-add/remove. An early draft guessed
onObserverAdded/onObserverRemoved and failed; the engine was right, the test was
wrong. The scenario now pins the transition-only semantics explicitly.
