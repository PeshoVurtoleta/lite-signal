lite-signal torture suite — complete set (27 scenarios)
========================================================

23 semantic (deterministic, fast, CI) + 4 soak (one opt-in). Full superset through 1.9.
Every scenario feature-detects and skips cleanly below its feature; runs green
from 1.4.x forward. Skips use exit 77 and the runner enforces version floors:
a scenario that skips while the engine is AT or ABOVE its floor FAILS the run
(a dropped export cannot be a green skip); the runner also caps each scenario's
wall clock (TORTURE_TIMEOUT_MS, default 300s -> FAIL, not a hang) and finish()
fails any scenario that reaches PASS having asserted nothing.

On THIS engine (1.9.0): ALL 23 semantic execute -- the first folder in the
line with ZERO floor-skips -- and the soaks run 3 + the opt-in wraparound.
dispose-torture ACTIVATES natively here (Symbol.dispose / `using` on
lifecycle objects: registry -> destroy, effect + createScope disposers ->
themselves, box PROTOTYPES shared per registry; callable value handles
deliberately unstamped). cleanup-return-torture runs the 1.8.0-origin native
SUPERSET (section 6b pins the 1.8 severTail cursor-repair by mechanism: five
named deterministic dispose-mid-retrack geometries, including the cursor
parked EXACTLY on the freed link and a survivors-intact headDep check).
flush-torture runs the 1.7.0-origin native superset (sections 7-10:
value-never-defers, FLAG_SCHEDULED enqueue dedup via op 7, the invalid-token
throw matrix, re-entrant flush).

SOAK: graph-fuzzer, scheduler-bench, torture-soak, wraparound-torture
  wraparound-torture (2026-08 Phase 4, OPT-IN via TORTURE_WRAPAROUND=1, ~30s;
  exits 78 otherwise): pins the 2^31 dormancy band at FULL DISTANCE (~2.1B
  real version spins per crossing). Pinned truth on 1.5.0: below the band
  (gap <= 2^31-65 verified) delivery is exact; inside the band
  (gap in [2^31-1, 2^32)) the FIRST dependency write after the dormancy is
  invisible -- unobserved pulls serve the stale cache, and observed cones
  skip the effect body entirely (executeEffect's dep-validation walk hits the
  same aliased signed diff); recovery is automatic and one-shot (the stale
  pull re-stamps evalVersion; the next write propagates). Raw signals immune.
  These pins document ACTUAL behavior; an engine that closes the band flips
  them deliberately. NOTE: the "indefinite uptime" doc claim is crash-true
  but needs the dormancy caveat.
  2026-08 Phase 2 -- every soak now carries three witnesses the post-teardown
  checks are structurally blind to:
  - MID-RUN HIGH-WATER: activeNodes/activeLinks sampled per tick, gated against
    the topology's theoretical maxima (mutant-verified vs a deferred-sever
    engine: fires on tick 1).
  - POST-GC heapUsed: forced-GC heap high-water within a fixed slack of the
    post-build baseline -- retention the pool counters cannot see
    (mutant-verified vs a full link graveyard: +151 MB in 2s).
  - SENTINEL DELIVERY: dedicated effects record the values they OBSERVE (the
    shadow oracles peek() storage only, so a flush/scheduler path that stopped
    DELIVERING passed forever). torture-soak/graph-fuzzer check synchronous
    delivery immediately after each write with exact run counts;
    scheduler-bench pins DELIVERY-BY-NEXT-TICK for its microtask sentinels
    (a dropped thunk or wedged drain fails; a delivery merely moved to a
    later-but-still-prior event-loop turn passes by design) plus exact
    counts at teardown.
    Mutant-verified vs a flush-loop drop. Random SUB-sentinel drops are caught
    probabilistically (the drop must land on a sentinel node); systematic
    wedges deterministically.

op-accounting uses the engine's OWN opcode counters instead of wall-clock — the
lesson from the 1.13 mark-lane review: count deterministic work, don't time it.
It runs from 1.4.0 (needs only onGraphMutation). See op-accounting-review/
FINDINGS.md for the instrumentation gap it uncovered: 1.5.0's clean short-circuit
saves dep-COMPARISONS, which no opcode emits — the analogue of the pre-1.13
missing mark lane. Recommendation there: add a "compare lane" (op 11/12) so the
short-circuit's benefit becomes a counted fact and its regression becomes
catchable.
